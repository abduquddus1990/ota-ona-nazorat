## 4. Ruxsatlar deklaratsiyasi (App content → Sensitive permissions)

### Background location (`ACCESS_BACKGROUND_LOCATION`)
**Feature:**
```
Parents see their child's last location and get "arrived at school / left
home" alerts for safe zones they set. This only works if the child's phone
can report location while the app is in the background, because children
do not keep the app open. A persistent notification is always shown on the
child's phone while location is collected, and the child can turn it off.
```
**Why not foreground only:** `Geofence arrival/departure alerts and the parent's "where is my child" request must work when the screen is off.`
Video: 5-bo'limdagi 1-video.

### Foreground service — location (`FOREGROUND_SERVICE_LOCATION`)
```
Type: location. The service keeps a visible, persistent notification
("Qalqon AI is active") on the child's phone while it shares location with
the parent, as required for parental monitoring apps.
```

### Usage access (`PACKAGE_USAGE_STATS`)
Alohida forma yo'q, lekin ilova ichidagi ochiq ogohlantirish bor (PairingActivity).
Tavsifda: "screen time per app for the parent".

### Monitoring app
Manifestda `<meta-data android:name="isMonitoringTool" android:value="child_monitoring"/>` ✅
Do'kon tavsifi "parental control" ekanini ochiq aytadi ✅, doimiy bildirishnoma ✅.
